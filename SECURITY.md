# Security Policy

## Supported Versions

We actively release patches and security fixes for the current major release of ClipVault.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

ClipVault is a 100% offline, local-first application with zero cloud tracking. However, if you discover any potential security vulnerability or local privilege escalation issue, please let us know immediately.

1. **Do NOT open a public GitHub issue.**
2. Send an email directly to **support@korvexa.app** with details of the vulnerability.
3. Include clear reproduction steps or proof-of-concept code.
4. We will acknowledge receipt within 24-48 hours and work on a prioritized patch.

Thank you for helping keep ClipVault safe and secure for the community!
